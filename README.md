# Class Review

A web-based classroom review game. This first version is the **teacher setup page**: choose how many teams will play and enter the questions.

## What you can do

- Select **2–8 teams**
- Add **multiple-choice** questions, type the choices, and mark the correct one
- Add **true/false** questions and mark True or False as correct
- Edit, delete, and reorder questions
- Download a quiz file or upload a previously saved one
- Work is saved in the browser so a refresh does not wipe the quiz

## Run it locally

Open the folder and start a simple web server:

```bash
npm start
```

Then visit [http://localhost:4173](http://localhost:4173).

You can also open `index.html` directly in a browser.

## Tests

npm test
